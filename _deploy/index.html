Capability boundaries

What the API can do

  • Text generation and chat
  • Function calling — OpenAI-compatible tools and tool_calls
  • Structured output — response_format: json_object
  • Reasoning — thinking mode on by default, the trace returned in reasoning_content
  • Image understanding — images as input
  • 1M token context window, up to 384K output tokens

What it cannot do

  • Image generation
  • Audio or video generation

Responses come from the upstream model and can be wrong. Verify anything important yourself before you rely on it.

# One request, no SDK required
curl https://api.thelsy.com/v1/chat/completions \
  -H "Authorization: Bearer $THELSY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-flash",
    "messages": [
      {"role": "user", "content": "Draft a launch email."}
    ]
  }'
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.thelsy.com/v1",
    api_key=os.environ["THELSY_API_KEY"],
)

resp = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "Refactor this migration script."}],
)

print(resp.choices[0].message.content)
print(resp.usage)  # prompt, completion and cache tokens
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.thelsy.com/v1",
  apiKey: process.env.THELSY_API_KEY,
});

const res = await client.chat.completions.create({
  model: "deepseek-flash",
  messages: [{ role: "user", content: "Summarise this thread." }],
});

console.log(res.choices[0].message.content);
# Streaming, with a usage report in the final chunk
stream = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "Write a changelog."}],
    stream=True,
    stream_options={"include_usage": True},
)

for chunk in stream:
    if chunk.usage:
        print("billed:", chunk.usage.total_tokens)
    elif chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
Codex CLI

Point Codex CLI straight at Thelsy.

The Codex CLI can use this service directly. Add the block below to your Codex config (default ~/.codex/config.toml), and Codex will run on deepseek-flash through our endpoint.

~/.codex/config.toml 
model = "deepseek-flash"
model_provider = "custom"
disable_response_storage = true

[model_providers.custom]
base_url = "https://api.thelsy.com/v1"
wire_api = "responses"
disable_response_storage = true is required. Without that line the request fails with stream closed before response.completed. Keep it exactly as written above.
Claude Code

Point Claude Code straight at Thelsy.

We serve an Anthropic-compatible endpoint on the same host. Set the two variables below and Claude Code runs on deepseek-flash through your plan — streaming, tool use and system prompts included.

terminal 
export ANTHROPIC_BASE_URL="https://api.thelsy.com"
export ANTHROPIC_AUTH_TOKEN="sk-your-thelsy-key"
claude
On Windows PowerShell, set the same two variables with $env:ANTHROPIC_BASE_URL = "https://api.thelsy.com" and $env:ANTHROPIC_AUTH_TOKEN = "sk-your-thelsy-key", then run claude. Install it first with npm install -g @anthropic-ai/claude-code.

FAQ

Questions worth asking a gateway

Which models can I call today?
Right now the catalogue is deepseek-flash (DeepSeek Flash), served on the OpenAI-compatible endpoint at https://api.thelsy.com/v1. More channels are added to the same endpoint and announced in the changelog, and the live status of each model is always visible in the console.
Do I have to rewrite my integration?
No. We speak the OpenAI wire format, so you keep your SDK, your streaming parser and your tool-calling code. Point base_url at https://api.thelsy.com/v1, swap in your Thelsy key, and keep the model names you already use.
How exactly am I billed?
Per token, per request. Input, output and cache tokens are counted separately and shown on each line of the usage log, so a cache hit is visibly cheaper than a cold prompt. Your included tokens are drawn down first; when they run out, calls stop until you add more tokens or move up a plan. Nothing is ever billed beyond your subscription price.
How quickly do coding agents use up a plan?
Much faster than chat. Claude Code and Codex CLI resend a long context on every turn, so a single task can move hundreds of thousands of tokens — a Starter allowance that comfortably covers a month of ordinary API calls can be spent in days of heavy agent use. Prompt caching makes the repeated part cheaper, and every request is itemised in your usage log. Once the tokens included in your cycle are used up, calls stop until you add more or move up a plan; if you intend to run an agent all day, Pro or Business is the better seat.
Will you ever silently switch my model?
Never. Charging for a frontier model while quietly serving a weaker one is the fastest way to destroy a developer's trust, and it is off the table by policy. If a route has to change, it is published with a date and the change is visible in your call log.
What happens to my prompts and completions?
Requests are desensitised before they are written to a log, records are kept for six months for accounting and abuse review, and nothing is sold or used to train a model. Business customers can ask for request-body logging to be switched off entirely, keeping only the metering record.
How do I pay, and can I get an invoice?
Any major card, billed in USD through our payment provider — no mainland wallet or phone verification needed. A receipt is issued for every charge, and Business plans can request invoices with company details for accounting.
Where is this hosted, and who can use it?
The gateway runs on infrastructure in Hong Kong with HTTPS end to end. Thelsy is open to developers worldwide except where sanctions or our Acceptable Use Policy prohibit it — no malware, no spam, no fraud, and no reselling access to banned regions.
